# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment, no spam and no links to modified or
cracked builds. Maintainers may remove comments, issues or discussions that break these rules
and may block repeat offenders.

Report problems to **support@raincleaner.eu**.
