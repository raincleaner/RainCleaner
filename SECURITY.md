# Security Policy

## Reporting a vulnerability

Please report security issues privately to **security@raincleaner.eu**
(also listed in [/.well-known/security.txt](https://raincleaner.eu/.well-known/security.txt)).
Do not open a public issue for a vulnerability before it has been looked at.

Useful in a report: the Rain Cleaner version (shown at the bottom of the program's menu),
the Windows version, the steps to reproduce and what an attacker could do with it.

You will get an answer within a few days. Fixes ship as a normal release and are noted in the
[changelog](CHANGELOG.md).

## Supported versions

Only the latest release receives fixes. Rain Cleaner checks for updates on start and shows a
bar when a new version is out.

## Verifying a download

Each release lists the SHA-256 of the installer and the portable ZIP. The current values are
also at [raincleaner.eu/trust](https://raincleaner.eu/trust). Official sources are
raincleaner.eu, this repository, WinGet (`TVasilev.RainCleaner`) and Chocolatey (`raincleaner`).
Any other copy, and any "Pro" or "portable Pro" build, has been modified by someone else.
