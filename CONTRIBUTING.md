# Contributing

The source of Rain Cleaner is not public, but there is plenty you can help with.

- **Report a bug:** [open a bug report](https://github.com/raincleaner/RainCleaner/issues/new?template=bug_report.yml).
  Attach the redacted export from History → Export if the bug is about something the program changed.
- **Suggest a feature:** [open a feature request](https://github.com/raincleaner/RainCleaner/issues/new?template=feature_request.yml)
  or vote on ideas in the [community forum](https://raincleaner.eu/community).
- **Translations:** the program and site are in English, Bulgarian, German, Spanish, Russian and
  Turkish. Found a clumsy phrase? Open an issue with the screen and the better wording.
- **Security issues:** never in public — see [SECURITY.md](SECURITY.md).

Please keep to the [Code of Conduct](CODE_OF_CONDUCT.md).
